# 週別支出推移 BarChart 設計

## 目的

週次サマリーを開いたユーザーが、対象週の支出を直前の週や平常時と比較し、使いすぎを短時間で判断できるようにする。分析ダッシュボードには広げず、週次の振り返りに必要な気づきへ集中する。

## 採用する方向

既存の日別折れ線グラフを、対象週を含む直近3週間の `@mui/x-charts` `BarChart` に置き換える。

検討した選択肢は次のとおり。

1. 直近3週間の週別BarChartへ置換（採用）
   - 週同士の大小を一目で比較でき、Issue #232 の目的に最も直接的に合う。
   - 既存の日別比較操作はなくなるが、情報量を抑えてモバイルでも読みやすい。
2. 週別BarChartと既存の日別折れ線を併置
   - 日別の詳細を維持できる一方、カードが大きくなり、初期スコープを超える。
3. 日別データを棒グラフに置換
   - 既存機能を小さく変更できるが、「今週・前週・平均」を週単位で判断する目的を満たさない。

## 表示仕様

- 表示対象は、閲覧中の対象週、1週前、2週前の3週間とする。
- 現在週を閲覧している場合の短縮ラベルは `今週`、`先週`、`2週前` とする。
- 過去週を閲覧している場合は、誤って「今週」と表示せず、各週の開始日を `M/D週` 形式で表示する。
- グラフ上部に次を表示する。
  - 対象週の支出合計
  - 直前週との差額
  - 直前2週間の平均に対する比率
- 平均は対象週を含めず、直前2週間の支出合計の算術平均とする。
- 直前2週間がともに0円の場合、平均比は計算せず `比較データなし` と表示する。
- 前週差は前週データが取得できる限り0円も有効値として扱う。
- 金額は日本円表記とし、小数を表示しない。

## Tooltip

各棒をホバーまたはタップした際に、次を確認できるようにする。

- 対象週の日付範囲
- 支出合計
- その週の直前週との差額
- その週より前の最大2週間の平均との差額

3週間の表示範囲より古い比較元がない項目は `比較データなし` とする。既存の日別データポイントクリックと入出金比較Dialogは廃止し、Tooltipを詳細確認の主操作にする。

## コンポーネントとデータフロー

- `SummaryPage` は既存の `getFourWeeksSummary` queryから対象週を含む4週間の合計を受け取る。
- UIには新しい3週間だけを表示し、最古の1週間は表示週の比較値を計算するためだけに使う。
- `buildWeeklyExpenseChartData` は日付と合計から、表示ラベル、差額、平均差を持つUI用データを生成する純粋関数とする。
- `WeeklyTrendChart` は集計を行わず、整形済みデータの要約と `BarChart` を描画する。
- 週次サマリーrouteは遅延読込し、初期画面へCharts bundleを持ち込まない。
- 既存の `DailyComparisonDialog` と `useDailyComparison` は週別グラフから切り離す。ほかに利用箇所がなければ削除する。
- Convexのschema、認可、保存処理は変更しない。

## UI状態とアクセシビリティ

- 読み込み中は見出しと固定高のSkeletonを表示する。
- 3週間すべて0円の場合は、グラフの代わりに短い空状態を表示する。
- query全体の失敗は既存のページAlertで扱う。
- グラフ高はモバイルで約220pxとし、凡例は表示しない。
- グラフだけに情報を閉じ込めず、上部要約を通常のテキストとして読めるようにする。
- 色だけに依存せず、週ラベルと金額で棒を識別できるようにする。
- `prefers-reduced-motion` またはテスト環境ではアニメーションを抑制できる構成にする。

## テスト方針

- 純粋関数のユニットテストで、並び順、前週差、直前2週平均、0円時の扱い、過去週ラベルを確認する。
- コンポーネントテストで、要約、BarChart、Tooltip用データ、空状態、Skeletonを確認する。
- 既存E2EのSVG `circle` クリック前提を削除し、週次サマリーにBarChartと要約が表示されることを確認する。
- Tooltipの細かな計算値はユニットテストへ寄せ、E2Eでは主要表示とモバイル破綻の回帰に絞る。

## 対象外

- Zoom、Pan、Export
- 予算との比較
- MUI X Pro/Premium機能
- 日別比較Dialogの代替となる週別明細Dialog
