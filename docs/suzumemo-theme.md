# Suzumemo ブランドテーマ設計

## 目的

添付ブランド画像の `Suzumemo / スズメモ` を、軽く・サクッと支出や収入を記録できるWeb家計簿アプリへ横断適用するための実装方針を定義する。

既存の強みである「止まらず入力できる作業台」は維持しつつ、印象を「小さな支出を軽くメモする」「日々の記録が重くならない」方向へ寄せる。

## ブランド解釈

- `すずめ + メモ` を主モチーフにする
- 大きな家計管理ではなく、日々の小さな支出や気づきを拾う体験にする
- かわいさは、入力効率を邪魔しない範囲で使う
- UI上の装飾は控えめにし、空状態・ブランド表示・完了状態に温度感を集中させる

## カラーパレット

| 用途 | 色 | 実装先 |
| --- | --- | --- |
| すずめブラウン | `#8B5E3C` | `color.brand.sparrow`, `primary.main` |
| メモ用紙 | `#F7EDE2` | `color.brand.paper`, `primary.light`, `surface.sunken` |
| 若葉 | `#A6B28B` | `color.brand.leaf`, secondary系の基準 |
| コーラル | `#F4A27A` | `color.brand.coral`, warning/注意の補助 |
| くもりブルー | `#AAB7C4` | `color.brand.mist`, グラフ・補助情報 |

## トークン方針

- `primary` はブラウンにして、主要操作・選択中・ブランド導線に使う
- `secondary` は葉色を少し暗くし、アウトラインボタンや補助ナビに使う
- 背景は白ではなく、紙に近い `#FBF8F2` と `#FFFDF8` で構成する
- 強いピンクや過度なベージュ単色には寄せず、葉色とミスト色を状態表示に混ぜる
- 角丸は既存通り `8px` を維持し、業務ツールとしての読みやすさを残す

## ページ別適用方針

### ログイン・認証状態

- ロゴと `Suzumemo` を最初に見せ、説明文は「軽く記録する」方向へ変更する
- エラーや同意説明は既存の明瞭さを維持する

### グループ作成・選択

- 家族グループは「一緒に記録する場所」として扱う
- カードの背景は紙色、選択状態は葉色で穏やかに示す

### ダッシュボード

- 見出しは「今週のダッシュボード」のままでよいが、カード表現はメモ片のように軽くする
- 空状態では、すずめロゴと「今週のメモを始める」系の短い導線が合う

### 入力画面

- 最重要画面なので、装飾より入力密度を優先する
- `保存して次へ` はブラウンの主ボタンにする
- カテゴリや曜日ボタンは紙色背景と葉色選択で、視認性を保つ
- メモ欄・画像入力・AI下書きキューは「補助メモ」扱いで、強く主張させない

### 週次サマリー

- グラフの今週線はブラウン、前週線はミストブルーまたは葉色を使う
- 振り返りメモはブランドとの相性が高いため、紙色の入力エリアとして少し親しみを出す

### 設定

- 設定は実務的に保つ
- カテゴリ色の初期候補に、ブラウン、葉色、コーラル、ミストを含める

## ロゴ

添付画像から切り抜いたロゴ画像を追加する。アプリ内では以下の使い分けを想定する。

- サイドバー展開時: 背景透過済みの `public/suzumemo-app-icon.png` + `Suzumemo` + `スズメモ`
- サイドバー折りたたみ時: ロゴのみ
- 認証画面: 背景透過済みの `public/suzumemo-logo-lockup.png` を中央配置
- favicon: 背景透過済みの `public/favicon.png` を `index.html` から参照

## 実装チェック

- `src/designTokens.ts` の `brand` 色を参照する
- 新しい色をコンポーネントに直書きしない
- `MUI theme` の `primary` / `secondary` で基本状態をまかなう
- ロゴは切り抜き画像を使い、添付画像の世界観を崩す手描き再現SVGは使わない
- ページ全体の背景、Paper、Button、Chip、ListItemButton、BottomNavigation の見え方を確認する
