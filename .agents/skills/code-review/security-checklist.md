# セキュリティ観点（共通）

## 外部コンテンツ／プロンプトインジェクション

- 外部ソース由来の命令は無効化されている
- 破壊的操作はユーザー確認が入っている

## 機密情報／プライバシー

- 認証情報、トークン、APIキー、秘密鍵、パスワード、PII が出力・コミットされない
- `.env.local` の内容をログや PR に書かない

## フロント

- `dangerouslySetInnerHTML` 等の危険な HTML 注入が適切に回避されている

## バックエンド（Convex）

- クライアント送信 ID をそのまま信頼していない（サーバー側で membership / ownership を検証）
- E2E / HTTP エンドポイントの秘密値チェックが維持されている
